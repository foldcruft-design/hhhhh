# 🛰 GEOINT Telegram Assistant Bot (aiogram 3.x)

Специализированный модульный Telegram-бот для геопространственной разведки (GEOINT), визуального OSINT-анализа и поиска первоисточников фотографий на базе нейросети **Google Gemini 3.8 Flash**.

---

## ⚡️ Возможности бота

1. **Анализ геопозиции по фото:**
   - Распознавание архитектурных элементов, стилей застройки и кровельных материалов.
   - Определение растительности, климатических зон и типа почвы.
   - Идентификация дорожной инфраструктуры: столбы ЛЭП, типы изоляторов, разметка, сторона движения.
   - Распознавание вывесок, языков, шрифтов и автомобильных номеров.
   - Оценка направления солнца и длины теней для верификации сторон света.

2. **Поиск страниц и первоисточников с фото (Reverse Search):**
   - Интеграция с Google Lens, Яндекс Картинки, Bing Visual Search, TinEye и PimEyes.
   - Автоматическая генерация специализированных Google OSINT Dorks по извлеченным ключевым словам и объектам.

3. **Краткие выводы и структурированные резюме:**
   - Экспресс-отчет с оценкой достоверности гипотезы (Высокая / Средняя / Низкая).
   - Интерактивные инлайн-кнопки для раскрытия подробных визуальных улик и следующих шагов верификации.
   - Автоматическое извлечение аппаратных координат GPS из EXIF (при отправке файлом).

4. **Встроенная панель администратора (`/admin`):**
   - Мониторинг статистики: количество пользователей, запросов, топ определенных стран.
   - Управление пользователями: просмотр профилей, блокировка/разблокировка нарушителей.
   - Просмотр истории расследований.
   - Массовая рассылка сообщений пользователям (Broadcast) с защитой от флуда и подсчетом доставок.

## 📁 Структура проекта

```
python_bot/
├── main.py                     # [1/7] Главный файл запуска бота, middleware и диспетчера
├── config.py                   # [2/7] Pydantic настройки, переменные окружения (.env)
├── database.py                 # [3/7] Асинхронный SQLite менеджер (aiosqlite)
├── geoint_service.py           # [4/7] Сервис GEOINT: Gemini 3.8 Flash, EXIF, обратный поиск
├── keyboards.py                # [5/7] Все Reply и Inline клавиатуры бота
├── handlers_geoint.py          # [6/7] Обработчики фото, команд /start, /help, /tools
├── handlers_admin.py           # [7/7] Панель администратора (/admin), статистика, рассылка
├── requirements.txt            # Зависимости Python (aiogram 3.x, pillow, aiosqlite, etc.)
├── .env.example                # Шаблон переменных окружения
├── Dockerfile                  # Контейнеризация для сервера/VPS
├── docker-compose.yml          # Запуск в 1 команду
└── README.md                   # Документация и инструкция
```

## 🚀 Быстрый старт

### 1. Клонирование и установка зависимостей
```bash
python3 -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Настройка переменных окружения
Скопируйте `.env.example` в `.env`:
```bash
cp .env.example .env
```
Заполните обязательные параметры:
- `BOT_TOKEN` — получите у [@BotFather](https://t.me/BotFather)
- `GEMINI_API_KEY` — получите в [Google AI Studio](https://aistudio.google.com/)
- `ADMIN_IDS` — ваш Telegram ID (узнать можно в [@userinfobot](https://t.me/userinfobot))

### 3. Запуск бота
```bash
python main.py
```
